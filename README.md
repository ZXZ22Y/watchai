# 腕上智析 · WatchAI

一款面向小米手表的 Android 健康数据分析 App。它**不接入第三方同步服务、不使用任何演示数据**，而是通过 Root 权限直接读取「小米运动健康」写入本机的真实健康数据库，并以 Apple 健康 / 主流运动 App 的风格呈现睡眠、运动、恢复与专业跑步指标。

> 所有分析均为**本机离线计算**，不上传任何健康数据，无需注册、无需联网、无需付费。

## 功能一览

### 今日（Overview）
- **身体准备度 1–10**：基于睡眠基础与个人 7 晚 HRV 基线综合评估
- **今日活动三环**：活动（步数）/ 锻炼（分钟）/ 站立（小时），Apple 健身风格渐变圆环
- **昨晚睡眠摘要**：时长、效率、分期条、恢复 HRV、睡眠债徽章，一键进入完整分析
- **核心指标**：心率 / 血氧 / 压力 / 锻炼时长，均可点击进入当日分时详情
- **近 7 天步数趋势**

### 锻炼（Workout）
- 本周次数 / 时长 / 距离 / 消耗统计
- 今日训练负荷趋势
- **专业跑步指标**：最大摄氧量 VO2max（年龄/性别/静息心率个体化）、跑力指数、Riegel 成绩预测、同龄人水平对比
- **个人最佳 PB**：最长距离 / 最快配速 / 最长时长 / 最高消耗
- 单场详情：
  - **卫星轨迹图**（高德卫星瓦片 + Web Mercator + WGS84→GCJ02）、连续速度色阶、每公里分段标点与分段速度条、起终点标记与逆地理编码
  - **心率区间分布 Z1–Z5**：按最大心率百分比分区，展示各区时长与占比
  - **跑步动态**：垂直振幅、触地时间、垂直步幅比、步频、步幅
  - 逐点曲线：心率 / 配速 / 海拔 / 步频 / 速度 / 垂直振幅

### 睡眠
- 睡眠评分与分级、睡眠时长/效率/深睡/REM 等关键指标
- 睡眠分期条与逐项明细、睡眠周期解读
- 睡眠债、作息规律性、HRV 相对个人基线的恢复评估
- 本周 vs 上周状态趋势、与目标对比

### 智能分析（Insight）
- 全部由本机实时计算，**完全离线**：准备度、睡眠与恢复分析、运动健康分析、训练建议、智能洞察、健康简报

### 设备与数据
- 连接状态诊断（Root 通道 / 数据库定位 / 解析结果）、诊断报告导出
- 身体资料设置（年龄 / 身高 / 体重 / 性别 / 静息心率）
- 数据源说明与自动同步设置

## 数据链路

本 App **唯一**的数据来源是「小米运动健康」App 写入本机的数据库：

```
手表（小米手表 S5 等）
   │  蓝牙
   ▼
小米运动健康 App（com.mi.health）── 手动/自动同步 ──▶
   ▼
/data/data/com.mi.health/databases/<账号ID>/cn/fitness_data
   │  Root 读取（自解析 SQLite B-tree 页，不依赖 sqlite3）
   ▼
腕上智析 WatchAI
```

- 使用 Root 常驻 shell + 自解析 SQLite 页结构读取数据。
- **每次打开 App 会自动同步一次**；右上角 `↻` 可手动立即刷新。
- 请先确保：手机已 Root（Magisk / KernelSU）、本 App 已获 Root 授权、KernelSU 环境下需为本 App 开启「全局命名空间」以便看到 `/data/data/com.mi.health`、并已在「小米运动健康」里同步过手表数据。

> 读取不到数据时本 App 一律留空，**绝不填充演示数据**，便于你确认看到的都是自己的真实数据。

## 构建

环境：Android SDK（compileSdk 34）、JDK 17、Gradle 8.x。

```bash
# 1. 配置本机 SDK 路径
echo "sdk.dir=/你的/Android/Sdk" > local.properties

# 2. 编译 Debug APK
./gradlew :app:assembleDebug
# 输出：app/build/outputs/apk/debug/app-debug.apk
```

项目为纯 Java + WebView 实现，`app/src/main/assets/app/app.html` 为界面与前端逻辑，`app/src/main/java/com/example/watchai/` 为数据读取、分析算法与 JS Bridge。
